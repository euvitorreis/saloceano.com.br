# SAL OCEANO aromas — Site Institucional

Site institucional da marca **SAL OCEANO aromas**, disponível em [www.saloceano.com.br](https://www.saloceano.com.br).

## Sobre

Site single-page em HTML puro com CSS e JavaScript inline. Apresenta a marca, linhas de produtos, formatos de presença (Loja Conceito, Quiosques, Spa & Amenities) e o Projeto Resort.

## Tecnologias

- HTML5 / CSS3 / JavaScript vanilla
- Google Fonts: Cormorant Garamond + Montserrat
- Formspree para formulário de contato
- Unsplash CDN para fotos de cenário (hero, jornada, resort)
- Imagens locais em `imagens/`
